# Documentation

A few pages for players, pack makers and anyone curious about what's under the hood.

- **[Compatibility](compatibility.md)**: which mods work together with NTM: DE, and what to keep in mind.
- **[Differences from NTM: NEXT](differences.md)**: what we fixed, what we added, and the few things 1.21.1 simply can't do.
- **[ComputerCraft](computercraft/README.md)**: every NTM peripheral, plus a script that pokes all of them.
- **[How the backport works](how-it-works.md)**: how a 26.2 mod ends up running on 1.21.1, and how it keeps up with upstream.

For the mod itself (machines, reactors, recipes) the best places are the in-game guides, JEI, and the
[official NTM wiki](https://nucleartech.wiki/wiki/Main_Page). Almost everything written there for NTM applies here too.
