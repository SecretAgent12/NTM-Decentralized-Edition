# com.hbm.lib.crankshaft

The Java files in this package are ported from **CrankShaft** (https://github.com/Warfactory-Official/CrankShaft),
an unofficial port of Flywheel (https://github.com/Engine-Room/Flywheel) to Minecraft 26.2.
They were modified by SecretAgent12 (NTM 1.21.1 backport): package relocated from `dev.engine_room.flywheel.*` to
`com.hbm.lib.crankshaft`, ported to Flywheel 1.0 / Minecraft 1.21.1. The GLSL files under
`assets/hbm/flywheel/{instance,material,cutout,light}/crankshaft/` are ported likewise.
